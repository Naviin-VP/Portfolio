# Navin VP — Portfolio

A responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Structure

```text
navin-vp-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── navin-photo.jpg
    ├── navin-signature.png
    └── Navin-VP-Resume.pdf
```

## Features

- Responsive design
- Animated hero section
- Professional photo
- Animated scrolling/reveal effects
- Technology marquee
- Interactive experience filters
- Certification cards with verification links
- Mobile navigation
- Scroll progress indicator
- Subtle cursor glow
- Hero photo tilt effect
- GitHub Pages ready

## Before publishing

1. The LinkedIn profile link is already configured in `index.html`.
2. Place the PDF resume at `assets/Navin-VP-Resume.pdf`. The portfolio already includes animated "Resume" download buttons in the navigation and resume CTA section.
3. Keep all asset filenames exactly as referenced in `index.html`.

## GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Push to `main` or run the **Deploy portfolio to GitHub Pages** workflow from the **Actions** tab.

The workflow publishes the static site automatically. Once its first run succeeds, open **Settings → Pages** to find the live site URL.
