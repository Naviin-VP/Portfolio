# Navin VP — Portfolio

A responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Structure

```text
navin-vp-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── navin-photo.jpg
    ├── navin-signature.png
    └── Navin-VP-Resume.pdf
```

## Features

- Responsive design
- Animated hero section
- Professional photo
- Animated scrolling/reveal effects
- Technology marquee
- Interactive experience filters
- Certification cards with verification links
- Mobile navigation
- Scroll progress indicator
- Subtle cursor glow
- Hero photo tilt effect
- GitHub Pages ready

## Before publishing

1. The LinkedIn profile link is already configured in `index.html`.
2. Place the PDF resume at `assets/Navin-VP-Resume.pdf`. The portfolio already includes animated "Resume" download buttons in the navigation and resume CTA section.
3. Keep all asset filenames exactly as referenced in `index.html`.

## GitHub Pages

1. Create a GitHub repository such as `navin-vp-portfolio`.
2. Upload all files and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

The site will then be available through the GitHub Pages URL shown by GitHub.
